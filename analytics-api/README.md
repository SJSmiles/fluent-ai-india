# 📊 Fluent-AI Analytics API

Analytics service for tracking language learning progress, conversation quality, and OpenAI API usage.

## 🎯 Purpose
- Language learning progress tracking
- Conversation fluency analysis
- OpenAI API usage and cost monitoring
- User engagement metrics
- Learning effectiveness insights

## 🛠️ Tech Stack
- **Language**: Python + FastAPI
- **Database**: ClickHouse / TimescaleDB
- **Analytics**: Pandas, NumPy
- **ML**: scikit-learn for fluency scoring
- **Visualization**: Plotly, Matplotlib

## 🚀 Quick Start
```bash
npm install
npm run dev
# Analytics API at http://localhost:3003
```

## 📈 Analytics Features
- Real-time conversation quality metrics
- Language fluency progression tracking
- OpenAI API cost optimization insights
- User learning pattern analysis
- Comparative fluency benchmarking

## 🎯 Learning Metrics
- Words per minute improvement
- Grammar accuracy tracking
- Pronunciation quality scores
- Vocabulary expansion monitoring
- Conversation confidence levels
- OpenAI token usage optimization

## 🔗 Related Services
- Collects data from: All services
- Serves insights to: `admin-panel`
